# Rose Quartz Massage

A static first build for Rose's nature-led massage business website.

## Open locally with Vite

```powershell
npm install
npm run dev
```

Then open the localhost URL printed by Vite.

## Current build includes

- Full responsive landing page
- Optimized generated hero, prenatal, brand mood, and journal imagery
- Specialist service menu with room for expansion
- Interactive Rose Session Map body-map intake
- Booking request interaction
- Care standards page for consent, privacy, prenatal safety, lymphatic cautions, and scope of practice
- Privacy and intake page for sensitive body-map details and future AI-assisted summaries
- 36-article journal library with optimized article-specific header images and a browsable all-articles page
- AI experience roadmap in `docs/ai-experience-roadmap.md`
- Competitive research notes in `docs/research.md`
- Launch SEO/domain checklist in `docs/launch-seo.md`
- Launch readiness checklist in `docs/launch-readiness.md`
- Production sitemap tooling with `npm.cmd run sitemap -- --site-url=https://your-real-domain.com`
- Brand favicon, web manifest, robots rules, social metadata, and JSON-LD structured data

## Before launch

Add Rose's license number, booking platform, contact details, location or service area, cancellation policy, contraindication language, testimonials, final photography, canonical production domain, generated sitemap, and absolute metadata URLs.
